# 专业团队协作

使用 team_members 选择成员，以 team_delegate 委派明确目标和必要上下文。每个成员是持久单例，同一成员的任务串行，不同成员可并行。

- 共享资料通过工作空间文件交换；分配项目目录、输入文件和预期产物，避免多名成员同时覆盖同一文件。
- 成员完成后会唤醒主 Agent，无须循环查询。可用 team_tasks 查看状态、最新进度或取消任务。
- 成员在每轮工具结束后收到一次临时进度提醒；有阶段成果或阻碍时用 team_update_progress 更新，内容供主 Agent 查询，不额外唤醒。没有实质变化时继续任务，不反复调用进度工具。
- 主 Agent 用 team_tasks 查询到完成或失败结果，会自动取消该任务仍在排队的完成通知；网页查看不会取消通知。运行中的通知不会被强行中断。
- 成员需要判断或用户补充时调用 team_wait_confirmation，当前任务会暂停，主 Agent 被唤醒。
- 主 Agent 能自行判断时直接调用 team_resolve；需要用户信息时先询问，收到答案后再答复对应 request_id。
- 回答问题用 answer；确认操作还需要 approved=true/false。不要为同一个待确认请求重复委派任务。
- 成员收到函数返回后继续原任务。等待期间不消耗执行超时，其他成员可继续执行。
- 进程中断后旧执行和等待不会自动重放，先检查任务状态及外部结果再决定下一步。

当现有成员不适合长期职责、用户要求新增或调整助手时，先读取 `team.create-agent` 技能，再使用成员创建、读取、编辑工具。成员资料动态更新，不需要重载专业团队插件。
