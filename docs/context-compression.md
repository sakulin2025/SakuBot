# 上下文压缩与归档

固定提示、有限工作摘要、近期原文、当前任务及临时要求组成上下文。摘要是历史资料，不是授权。

压缩、请求预检和用量显示统一估算Token，区分ASCII、非ASCII和图片；收到prompt_tokens后校准当前进程模型系数。它不是供应商原生分词器的精确计数。超窗明确报错，不再静默删除历史。

近期原文通常保留约12000估算Token，手动约2000，至少最后一个完整历史单元。当前唤醒保留。历史按完整事件选择范围，长任务按完整工具批次边界选择，不能拆开请求与结果。大工具正文和参数给模型受限预览，完整原文保存在SQLite context_archives。

各段独立摘要，不逐片重写累计摘要。成功段落按内容哈希复用；最后用旧工作摘要和新增归档摘要生成一次有限工作摘要，保留来源、稳定身份ID、已执行动作、失败和待办。仍可能遗漏细节，重要内容用context_archive的list/search/read找回原文。

达到阈值75%后可后台准备归档，只缓存、不改上下文。真正触发后才替换。失败保留原文并冷却120秒，能装下时继续，不能则明确报错；手动失败显式报告，未减少上下文不替换。归档按智能体隔离，清空上下文同时取消准备并删除该智能体的归档查询资料，原有聊天和审计日志保留。

完整记录阶段、模型请求体、响应、用量、错误、归档ID和工作摘要；网页显示开始/完成/失败。过程事件投递遵守同步工具过程设置及本轮发送开关。运行设置compression_notice为空不发送；真正压缩开始且主智能体send_result_to_source=true时向当前主会话源发送文本，独立于工具过程开关，不进入模型历史。默认“稍等，脑子太乱了，给我点时间让我整理一下思绪”。
