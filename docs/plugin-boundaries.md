# 插件边界检查 · 0.15.1

本轮采用静态检查和生产构建，未运行功能测试。

| 范围 | 检查结果与调整 |
| --- | --- |
| QQ / NapCat | 连接客户端、原生消息解析、连接配置、页面、身份指引、人物数据和原生发送全部迁入 QQ 插件；核心不持有 QQ 客户端或平台配置字段 |
| 主导览与导航 | 插件提供页面和可选主导览建议，卸载自动移除；核心导航不再包含连接页面 |
| 通知投递 | 核心只维护通用投递适配器与记录，平台解析与实际发送由插件处理 |
| 外部消息回应 | 只依赖规范化消息及源声明的身份标记，不读取 QQ 配置或客户端 |
| 长期记忆 | 初始化自己的记忆表，移出 QQ 人物查询；事件搜索使用通用历史接口 |
| 定时任务 | 自行初始化任务表，触发通用 context/wake/notify；不依赖平台客户端 |
| 专业团队 | 自行初始化任务和待确认表，持有自身的中断恢复逻辑；使用公共 Agent 声明和实例接口 |
| 工作空间 | 工具、页面、模型使用指引属于插件；核心只提供通用文件和进程服务 |
| 技能 | 读取工具和模型使用指引属于插件，解析与索引为通用服务 |

共享 SQLite 数据库、文件服务、Agent、技能解析、规范化消息与事件队列是公共框架服务，不因某个插件关闭而删除。已有业务表沿用原名称，数据不删除。

QQ 的一次性迁移脚本位于 `sakubot/plugins/qq/migrate.py`，部署停机时执行，迁出旧全局配置并补齐旧消息的上下文可见性元数据；配置与数据库备份保存到 `data/migrations/before-qq-plugin-*`。仅对未经修改的旧默认人格去除原先写死的 QQ 身份，自定义人格保持原样。

外部消息回应现为 QQ 内部模块，统一在 QQ 管理页的标签中配置；不再存在独立插件，两个助手 Agent 由 QQ 声明。
