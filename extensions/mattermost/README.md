# Mattermost 主会话

启用插件后，在「会话连接 → Mattermost」页面填写服务器地址、机器人访问令牌和主人的用户 ID 或用户名（可加 `@`）。保存时验证账号，然后自动连接主人的私聊。页面提供连接状态、重连和近期日志；日志不记录令牌与消息正文。机器人账号需要能够读取用户资料、创建私聊和发送消息。

只处理绑定主人的私聊，不接收群组或其他私聊作为唤醒。通过主对话响应模式配置 Mattermost 是否接收结果。支持文本、图片、语音、视频、文件和工具调用开始通知；接收的附件保存到工作空间 `inbox/mattermost`。不实现流式分段输出。历史补收依赖服务器的消息接口，首次绑定只处理绑定后的消息，重连时尝试补收。大文件上限 20 MiB。

WebSocket 和文件服务由 Mattermost 提供，Token 使用 Bearer 认证。连接状态和错误可从插件状态查看。

Agent 工具包含用户、团队、频道和消息查询，发送消息与附件、消息编辑删除、表情、置顶、文件上传下载，以及 `mattermost_request` 官方 JSON API 入口。工具仅在插件可用且对该 Agent 可见时提供，权限取决于 Mattermost 机器人账号。附带 `mattermost` Skill。
