# 音频终端插件 0.4.0

设备控制、事件与独占音箱主会话源。支持旧服务端 ASR/TTS，以及由 Sakubot 的独立 ASR/TTS 模型处理音频、按句流式播报和自动打断。

完整配置、协议边界、测试及230部署回滚见 [音频模型与音箱主会话](../../docs/audio-models.md)。

- 不将双敲事件自动提交主 Agent；路由由桥接配置。
- `audio_terminal_end_conversation()` 无需参数，立即结束当前音箱会话。
- 页面「打断并继续听」保留会话，「结束会话」释放锁。
- 标准 MiMo ASR 支持整段音频输入与流式文字输出，不支持实时麦克风输入。模型管理页的 ASR、TTS、流式与实时标签分别设置。
- 原配置保留，升级后需选择语音处理方式与 ASR/TTS 模型。
