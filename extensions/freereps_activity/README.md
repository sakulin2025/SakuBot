# FreeReps 活动数据同步

插件提供查询、训练报告和轮询。事件动作统一配置于“事件与脚本”。

## 新增训练记录

开启轮询后声明并发布 `freereps_activity.workout_added.*`，参数 `workout_type` 为可选训练名称关键词。

首次成功查询只建立基线，升级保留原基线。后续每发现一条新的训练记录发布一个事件；同 ID、同名称且开始时间相近的跨来源记录合并。重复同步、训练状态或详情更新不会重复触发。不要求训练已结束，不按训练结束距今时长过滤；回看范围之外的记录不会被查询。

事件 data 包含 `workout`（ID、名称、来源、开始/结束、时长）和 `observed_at`。同步时间不等于训练结束时间。待发布事件持久保存并使用稳定 UID，框架按绑定去重。

不再每轮发布“同步完成”，不再提供插件内事件规则或直接唤醒、通知、上下文注入。需要处理时在事件目录绑定动作。

## 升级

保留训练去重基线。原具名训练完成绑定迁为新增记录绑定（若没有占用）；单条启用的、无延迟 wake 规则自动迁入直接唤醒绑定。其他旧规则及待提交记录保存在插件 KV `legacy_events_v1`，不会自动重放；多个动作、延迟或通知规则需要手动改为脚本。旧 `sync_completed` 绑定不会再被本插件触发。
