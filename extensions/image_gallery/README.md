# 图库

公共取图、按ID取图、图库管理API、合集收藏及随机推送事件。管理密码使用图库ADMIN_PASSWORD，不是NapCat Token。内部URL与外部推广URL分开，密码和Cookie不提供给模型。

设置入口在插件列表的“设置”。密码非空时注册gallery_api；保存密码时通过登录及auth/check验证，错误不覆盖旧配置。空密码字段保留原值。公共取图在未配置密码时仍可使用。

推送默认关闭。独立target默认sakubot_gallery，不能与原NapCat adaptor共用。默认随机60～120分钟领取1～3张，23:00～09:00免打扰，时区Asia/Shanghai；可调整模式、图源、受限图片和审核后延迟。首次加载/重载只安排等待，不试取图。没有启用且有效的事件绑定时不领取。

在“事件与脚本”绑定image_gallery.push_received，选择脚本或wake提示词。数据为batch_id、target、image_ids、replay、fetched_at，没有图片本体。先持久批次，再登记事件；重发队列登记后确认，框架UID负责重复登记去重。登记不代表后续脚本执行或图片发送成功。原updates领取时立即写推送记录，网络结果未知或领取到本地保存之间崩溃仍可能丢失；此限制需要上游领取确认协议才能消除。

管理页展示最近取图、轮询状态和最近100个领取批次。本地outbox未完成时先恢复，不继续领取；更换图库地址时旧批次保留，恢复原地址完成后再切换。

技能及完整接口说明位于skills/usage/SKILL.md与其references/api.md，含收藏管理的请求体、字段、顺序、部分成功和调用示例。返回说明在tool_documentation.json。全部文档为普通资料，无强制typing开发约束。

文件大小配置：取图下载上限和API文件传输上限均允许1～500MiB，新安装默认各100；已有max_bytes迁移到取图下载上限并保留原数值。下载分块落盘并清理未完成临时文件，上传使用文件流。取图超限可回退预览；API文件超限明确报错。图库使用扩展的附件发布上限，其余插件默认附件限制不变；外部消息平台的限额也不变。

## 提前获取推送

调用 `gallery_push_now()` 可请求提前一次已有推送检查：下次检查还需超过10秒则提前执行；10秒内保持原计划；正在执行或已请求提前时不重复领取。工具仅返回调度状态，图片ID通过 `image_gallery.push_received` 事件交给绑定动作，不直接返回图片。默认遵守免打扰；传入 `gallery_push_now(ignore_quiet=true)` 可仅让本次请求对应的下一次检查跳过免打扰，不修改长期配置。下次在10秒内时保持时间不变，但仍应用这一次免打扰豁免；重复请求不重复领取。关闭轮询、缺少配置或无启用事件绑定时不绕过限制。执行完成后按配置范围内的自适应随机间隔重新安排，不再额外保留旧定时点。

## 自适应随机间隔

下一次间隔根据最近一次成功领取的实际数量与本次尝试数量决定，始终位于配置的最短、最长分钟数之间。取满时用Beta(1,3)偏向短间隔，未取满（包括0张）时用Beta(3,1)偏向长间隔；期望位置分别是区间的25%和75%，并非固定等待时间，也不不断累积退避。上下限相同时为固定间隔。

实际数量按有效图片ID去重计数，尝试数量是这次随机选择并传给上游的count，而不是配置的最多张数。重发队列和普通推送都按实际领取结果判断。反馈持久保存，重启后保留；没有反馈或切换了图库地址/推送目标时先均匀随机。请求异常、免打扰跳过、未领取或仅重投递旧批次不会覆盖上次领取反馈。保留重载前已排定的next_at，不因热重载立即取图。
